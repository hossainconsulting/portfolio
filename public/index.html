How the projects work

Each Salesforce project is a full engagement run end to end in its own Developer org: requirements gathered from stakeholders with conflicting priorities, a data model designed before anything is clicked, security and automation built and tested, and a written record of every decision.

The repositories contain the configuration, the seed data, and — most usefully — the deliverables: design documents, SOPs, analyses, incident write-ups and runbooks. The configuration proves the clicks happened. The documents prove the thinking did.

SunRise Solar Solutions

In progress
Salesforce Administrator

Twelve weeks as the incoming administrator at a 47-person NSW solar installer whose org has run unmaintained for six months — 340 duplicate accounts, a lead assignment rule that stopped matching reality when territory boundaries moved, and a quarter that missed quota with no explanation anyone can produce.

Delivered so far: a licence recovered by deactivating the provisioning account and re-pointing every automation that referenced it; duplicate accounts merged under a written survivorship rule, with the ambiguous groups escalated rather than guessed; matching and duplicate rules deployed; four operational reports; three SOPs; a 666-opportunity custody transfer; and a carry-forward register that names what is blocked and on whom.

Home Services AI

In progress
Claude Certified Developer — Foundations

Five tools for trades businesses, each targeting one place the work leaks money — enquiries never quoted, jobs never invoiced, calls missed after hours. Quote Triage turns a messy enquiry into a structured job spec and states what it still needs to ask. Notes to Invoice prices a day's work from a rates table without letting the model do arithmetic. Jobs MCP Server exposes a scheduling database to Claude with read tools and exactly one guarded write path. After-Hours Agent books the job or escalates a gas leak to a human. Eval Harness grades the other four across a fixed case set and reports accuracy, cost and regressions.

Delivered so far: the designs, a RAG maturity assessment that concludes four of the five tools should not be RAG systems at all, and a pruned analysis-prompt library where every prompt is allowed to find nothing.
