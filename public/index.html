What this is

Each project below is a full engagement run end to end in its own Salesforce Developer org: requirements gathered from stakeholders with conflicting priorities, a data model designed before anything is clicked, security and automation built and tested, and a written record of every decision.

The repositories contain the configuration, the seed data, and — most usefully — the deliverables: design documents, SOPs, analyses, incident write-ups and runbooks. The configuration proves the clicks happened. The documents prove the thinking did.

Disclosure

These are simulations, not client work. SunRise Solar Solutions, Meridian Field Services, TradeLink Group, Meridian Appliance Care, Coastline Retail Group, Ironbark Industrial Supply and Kurrajong Energy are fictional companies. Every scenario, stakeholder and record is invented for the purpose of developing and evidencing implementation skill.

No real customer data appears anywhere in these projects. I'd rather you know that in the first thirty seconds than find out later.

AI engineering

The other side of the same problem. The projects above configure the platform a trades business runs on; these build the tooling that plugs into it.

Home Services AI

In progress
Claude Certified Developer — Foundations

Five tools for trades businesses, each targeting one place the work leaks money — enquiries never quoted, jobs never invoiced, calls missed after hours. Quote Triage turns a messy enquiry into a structured job spec and states what it still needs to ask. Notes to Invoice prices a day's work from a rates table without letting the model do arithmetic. Jobs MCP Server exposes a scheduling database to Claude with read tools and exactly one guarded write path. After-Hours Agent books the job or escalates a gas leak to a human. Eval Harness grades the other four across a fixed case set and reports accuracy, cost and regressions.
