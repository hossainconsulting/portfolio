# Facebook Page

Older trades business owners and Sydney small-business groups. The Page is a
mirror; the value is in group answers and in the Meta Business Suite that
also runs Instagram.

## Page

| Field | Set to |
|---|---|
| Name | Hossain Consulting |
| Username | `@hossainconsulting` |
| Category | Business consultant · Software company |
| Intro (255) | Brand kit → Facebook intro |
| About | GBP description |
| Website | Hub with `utm_source=facebook&utm_medium=profile` |
| Location | Crows Nest NSW, address hidden, service area Sydney |
| Hours | Mon–Fri 9:00–17:30 |
| Action button | "Book now" → booking link, or "Learn more" → hub |
| Cover | 820×312 |

Connect the Page to the Instagram account in Meta Business Suite so one
scheduler posts to both.

## Content

- **One post a week**, the LinkedIn Monday post with the link in the body
  (Facebook does not punish links the way LinkedIn does).
- **Groups, twice a week.** Join Sydney tradie, small-business and startup
  groups. Answer CRM and admin questions in full. Never post a link
  unprompted; group admins remove it and members remember.

## Cadence

One Page post, two group answers a week.

## Metrics

Page reach, link clicks, messages. Monthly, from Meta Business Suite.
