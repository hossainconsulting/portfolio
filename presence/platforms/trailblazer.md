# Salesforce Trailblazer profile

The credential verifier. When a recruiter checks whether the certifications
are real, this is the page they land on. It is also a salesforce.com URL
pointing at you, which search engines weigh.

## Setup

| Field | Set to |
|---|---|
| Profile URL | `salesforce.com/trailblazer/<slug>` — set the slug to `hossainconsulting` if free |
| Visibility | Public, certifications shown, badges shown |
| Title | Salesforce Implementation Consultant, Hossain Consulting |
| Location | Sydney, Australia |
| About | First two paragraphs of the LinkedIn About |
| Website | The hub |
| Social | LinkedIn, GitHub, X |

## Certifications

Link Trailhead to Webassessor so passed exams appear automatically. Each
LinkedIn certification entry uses this profile as its credential URL.

## Trailblazer Community

Join the Sydney and the Australian admin groups. Answer questions in the
Trailblazer Community forum under the same rules as Reddit: answer fully, link
only when it is the direct answer. Community answers are indexed and rank.

## Metrics

Profile views (Trailhead shows a count). Rank progression is a vanity metric;
superbadges relevant to the certification track are not.
