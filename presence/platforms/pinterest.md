# Pinterest

A search engine for diagrams and checklists, with a long tail. Nobody is
hiring from Pinterest, but "salesforce ERD example" and "CRM implementation
checklist" are searched there and the pins link back to the hub for years.
Low effort: the carousels already exist.

## Boards

1. Salesforce diagrams (ERDs, security models, automation maps)
2. Implementation checklists
3. Agentforce and AI agent patterns
4. Certification study notes

## Pins

- 1000×1500, one diagram or one checklist per pin, title text on the image.
- Title: keyword first. "Salesforce ERD example: warranty administrator
  (Case, Entitlement, custom Warranty object)".
- Description: 2–3 sentences with the pillar keywords, the disclosure short
  form, link to the exact hub section or repo document.
- Alt text on every pin.

## Cadence

Monthly batch of 8–12 pins from the month's carousels, scheduled a day apart
in Pinterest's own scheduler.

## Metrics

Impressions, outbound clicks. Quarterly is enough.
