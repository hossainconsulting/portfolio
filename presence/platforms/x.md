## Bluesky

Register `hossainconsulting.bsky.social`, then set the handle to the domain:
Bluesky → Settings → Change handle → "I have my own domain" →
`hossainconsulting.com` → add the TXT record `_atproto.hossainconsulting.com`
with the value Bluesky shows, in Cloudflare DNS. The handle becomes
`@hossainconsulting.com`, which is a verification on its own. Mirror X.
