certification track. On this branch each also closes with a **Connect**

repos; `/presence-check` diffs them.

  warranty administrator, 12,400 cases/month, Agentforce Specialist track."
- **Website** — the hub.
- **Topics** — `salesforce`, `agentforce`, the cloud, `australia`, `portfolio`,
  `simulation`. Topics are indexed by GitHub search and by Google.

## Content

GitHub is not a social network to post on. The content is the commit history
and the deliverables. Two things help discovery:

1. **Releases.** Tag a release when an engagement milestone ships (`week-3`,
   `sprint-5`). Releases show on the profile feed and give a stable URL to
   link from LinkedIn.
2. **Discussions** off, Issues on. A recruiter may open one to ask a question.
   Answer it there.
