# 6. Retention and editing blueprint: video 1

Topic: five security questions, real org. Current average view duration:
none (first video). First benchmark: 50% AVD on an 11-minute video, which
YouTube treats as strong for tutorial content.

## Pattern interrupt map

Every 60 to 90 seconds the visual or the audio format changes. Screen
recording is the default; each interrupt leaves it.

| Time | Interrupt | Format change |
|---|---|---|
| 0:00 | Cold open on the record the user should not see | Full-screen org, cursor circling the amount |
| 0:30 | Exam guide page | Document, not org; zoom on the Security row |
| 1:30 | Q1 title card | Text on paper background, 2 s, mono tag "01 / 05" |
| 2:20 | The record disappears | Hard cut to the empty list, half a second of silence |
| 3:00 | Q2 title card | As Q1 |
| 3:45 | Role hierarchy drawn | Diagram overlay, three boxes, drawn in with the `draw` reveal |
| 4:15 | Q3 title card | As Q1 |
| 5:10 | "Two gates" diagram | Diagram overlay |
| 5:45 | Q4 title card | As Q1 |
| 6:30 | Split screen: profile on left, page layout on right | Two panels |
| 7:15 | Q5 title card | As Q1 |
| 8:15 | Rows reappearing in the report | Speed ramp, 2x, then hard stop |
| 9:00 | Three insights | Text on paper, one line at a time, voice slows |
| 10:15 | Repository page | Browser, not org |
| 10:40 | End screen | Board on paper background |

## Re-engagement lines (forward-looking, never a recap)

- **30% (about 3:20, inside Q2):** "The next one is the question that
  catches people who have actually studied, because the profile says Read
  and the org still says no."
- **50% (about 5:30, end of Q3):** "Question four is the one where you
  assign a permission set, refresh, and nothing changes. Two different
  reasons it happens, and the exam asks which."
- **70% (about 7:40, inside Q5):** "After this one I will give you the
  three lines I would write on the back of my hand, and an opinion about
  why the exam is really testing something else."

## B-roll and visual cut strategy per section

| Section | Cut rhythm | B-roll |
|---|---|---|
| Hook | One continuous take, 30 s, cursor as the only motion | None. The record is the B-roll. |
| Problem | Cuts every 8–10 s | Exam guide, a study-guide screenshot with "security" highlighted, a blank Developer org sign-up page |
| Each question | Setting change as one take; cut on the save; cut on the refresh | The diagram overlay for that question, drawn in over the org at 40% opacity |
| Insights | Text only, 20 s per line | None; the screen goes quiet on purpose |
| CTA | Browser, scroll the repo README slowly | The `deliverables/` folder listing |

Rules: no music under the org sections (the click and the silence are the
rhythm); a low bed under the insights only; no zoom-in on the presenter
because there is none; every setting change gets a mono caption in the
corner naming the Setup path so a viewer can pause and copy it.

## End screen sequence (10:40–11:00)

- 10:40 Voice: "Next Tuesday: profiles, permission sets and roles on one
  record, and the one diagram that makes them stop overlapping."
- 10:42 Board appears (paper background, system tokens): left element is
  the next-video card with its thumbnail; right element is a "the org is
  public" card linking the repository. No subscribe button element; the
  ask was made once in the CTA and a second ask lowers trust with this
  audience.
- 10:55 Voice: "Same org. Same user. See you then." Hold the board static
  to 11:00 so YouTube has a clean end-screen window.
