## Visual identity

Taken from the hub's stylesheet so every asset matches the site.

| Token | Light | Dark | Use |
|---|---|---|---|
| Paper | `#FAF9F7` | `#100F0D` | Backgrounds |
| Ink | `#141210` | `#EDE9E4` | Headline text |
| Ink-2 | `#4A4540` | `#A9A29A` | Body text |
| Key (green) | `#1B4D3E` | `#6FBFA3` | Accent, links, eyebrow labels |
| Key-soft | `#E6EEEA` | `#13251F` | Highlight blocks |
| Amber (in progress) | `#8A6410` | `#D8A94A` | Status badges only |

**Type:** structural text in Segoe UI / system sans; prose in Palatino / Georgia; code in a monospace. On social graphics use the sans for everything and keep the serif for the hub.

**Photo:** one headshot, neutral background, used unchanged on every platform. Crop square for avatars.

**Banner:** the eyebrow line, name, positioning sentence, hub URL, on paper background with the green key. Text stays inside the centre 60% so every platform's safe zone keeps it.
