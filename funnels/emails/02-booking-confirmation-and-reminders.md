# Sequence 2: Before the call (booking confirmed to call time)

Calendly sends the confirmation and reminders itself. Configure these in Calendly (Event type > Notifications and workflows) so nothing needs a second tool. Use the same wording; keep each under 120 words.
Booking is not marketing consent. These are service messages about a booking the person made. Do not add the booker to Sequence 1 unless they also ticked the opt-in box.

| When | Message |
|---|---|
| On booking | Confirmation (below) |
| 24 hours before | Reminder + prep questions |
| 1 hour before | Short reminder with the meeting link |
| Booker reschedules or cancels | Calendly default, plus a one-line note with the rebook link |

## Confirmation
Subject: You're booked: 20 minutes with Hemayet, {{date_time}}

Hi {{first_name}}, you're booked. The link to join is below.

Before we talk, it helps to have one recent enquiry in mind, from first message to job done, and a rough count of enquiries per week.

Please don't send passwords or customer records.

There's no obligation. If a project makes sense, I'll send a written scope and a fixed quote including GST afterwards.

If you can't make it, use the reschedule link. Hemayet

## 24 hours before
Subject: Tomorrow: our 20 minutes

Hi {{first_name}}, a reminder for {{date_time}}. Three questions to think about:
1. Where does an enquiry first land (phone, text, form, DM)?
2. Who replies, and how long does it usually take?
3. What happens to a quote after it is sent?
Rough answers are fine. Hemayet

## 1 hour before
Subject: Starting in an hour

Hi {{first_name}}, we start at {{time}}. Join here: {{meeting_link}}. If something has come up, rebook here: {{reschedule_link}}.
