# Notes

One file per module, written after the lab, named `NN-short-title.md`.

Each note answers four questions and nothing else:

1. **What was the lab?** One or two lines.
2. **What broke?** The errors, verbatim, and what they actually meant.
3. **What was the fix, and why does it work?** Not just the command — the reason.
4. **What would I do differently on a real system?** Where the lab was too easy.

A note that says "worked first time" is a sign the module was too easy and
should be made harder before moving on.
