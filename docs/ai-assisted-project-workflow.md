## Three ready-to-use requests

**SunRise Solar:** “Using the Week 4 build brief and carry-forward tickets, identify the highest-value lead-capture and attribution concepts I need this week. Give me three short exercises, their evidence files, and one question at a time to test understanding. This is a fictional Salesforce simulation. Do not mark work complete until the org or repo evidence supports it.”

**Home Services AI:** “Using the existing Quote Triage design and Eval Harness plans, propose synthetic cases for ambiguous trade, safety escalation, missing details and prompt injection. State expected routing, deterministic rules, model uncertainty and testable acceptance criteria. Keep all customer communication as a draft.”

**Integration Lab:** “Using current primary API documentation and the repo README, outline one small synthetic-data exercise for authentication, retries or idempotency. Cite sources, provide commands or code only after checking the actual stack, and separate design from verified execution.”

## Review rule

Before a generated result enters a README, case study or evidence record, compare each factual claim with the linked repo file, test result or primary source. Name the date and scope of any observation. Hemayet approves publication, client communication, job applications, spending and production deployment.
